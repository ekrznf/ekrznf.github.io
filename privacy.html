차원 대균열 런처 (Dimension Rift Launcher) · 시행일 2026-11-20

1. 수집하는 정보

런처는 마인크래프트 실행을 위해 마이크로소프트 계정 로그인을 사용합니다. 로그인은 마이크로소프트 공식 로그인 창에서 이루어지며, 런처는 비밀번호를 보거나 저장하지 않습니다. 로그인 결과로 받은 접속 토큰과 마인크래프트 프로필(닉네임 · UUID)만 사용자의 컴퓨터에 저장합니다.

2. 이용 목적

저장된 정보는 마인크래프트 게임 실행과 차원 대균열 서버 접속에만 사용합니다.

3. 제3자 제공 · 외부 전송

계정 정보를 운영자나 제3자에게 보내지 않습니다. 런처는 게임 파일을 받기 위해 Mojang · Fabric · 운영자 배포 서버에 접속하지만, 이때 계정 정보는 포함되지 않습니다.

4. 보관 · 삭제

정보는 사용자 컴퓨터의 런처 데이터 폴더에만 있으며, 런처의 계정 설정에서 로그아웃하거나 런처를 삭제하면 지워집니다.
